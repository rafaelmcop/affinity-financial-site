Affinity media relay — isolated prototype, NOT publicly deployed

Purpose: relay user-authorized HLS streams through a controlled HTTPS endpoint.
No vehicle motion restriction bypass, DRM circumvention or third-party service reuse.

Runtime: Node.js 22, built-in modules only. No npm dependencies.
Start: node services/media-relay/server.mjs
Required environment: MEDIA_RELAY_ACCESS_KEY, a private random key of at least 32 characters.
Optional: MEDIA_RELAY_PORT (60994), MEDIA_RELAY_PROVIDERS (dsaasd.online),
MEDIA_RELAY_ORIGINS (https://affinityfc.org,https://www.affinityfc.org).

The listener binds only to 127.0.0.1. Public hosting, valid TLS, portal-side
credential forwarding consent and access-key integration are separate pending steps.
Never place the access key in browser scripts or Git. Never log upstream URLs.

POST /v1/sessions requires Authorization: Bearer <private key> and a JSON
streamUrl on an allowlisted provider. The browser receives only an opaque path.
GET opaque media paths follows validated redirects and rewrites playlist resources.
DELETE /v1/sessions/<sessionId> requires private authorization.

Controls: public IPv4 destinations with DNS pinning; reserved/private IP denial;
restricted ports; 5 redirects; 30-minute in-memory expiry; 2 simultaneous sessions;
6 concurrent requests/session; 512 MiB/session; 16 MiB/media response; 1 MiB/playlist.
No playlists, user credentials, channel history or media files are persisted.
Expired/closed sessions are dropped from memory. Protected SAMPLE-AES/DRM manifests
are rejected. This relay does not transcode unsupported audio/video formats.

Do not route public video traffic through a general Cloudflare CDN/Tunnel plan.
Use hosting and a transport explicitly permitted for media. No paid service has
been purchased or new public infrastructure configured for this prototype.

Verification:
node --test services/media-relay/core.test.mjs
Tests cover authorization, token expiry, HTTP redirect handling, opaque playlist
rewrites, encryption-key URLs, restricted formats and private/reserved IP denial.
