Google and Microsoft integrations

This registers the platform application only. Each agent signs in to their own mailbox and grants access individually. No mailbox is shared.

Register a Web application with the provider and add these exact authorized redirect URLs:

https://portal.affinityfc.org/api/email-oauth/callback
https://www.affinityfc.org/api/email-oauth/callback

Google requires Gmail SMTP/IMAP access and may require app verification before general availability. Microsoft requires delegated IMAP.AccessAsUser.All, SMTP.Send and offline_access. Do not enter an email password here.

Secrets are encrypted server-side and never returned by this page.

In Testing, also add each Gmail address to the Google test-user list. Keep new connections disabled until provider setup is complete. Existing connected mailboxes are unaffected.
